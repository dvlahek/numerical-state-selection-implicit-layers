# v1.0.0 — Manuscript reproducibility snapshot

This release archives the reproducibility package for the manuscript

**Numerical State Selection Exposes Representation Ambiguity in Nonunique Implicit Neural Layers**.

## Included

- locked confirmation protocol and task-specific MRBI profile map
- core implicit-layer and MRBI implementation
- five numerical state-selection paths: Zero, Selected MRBI, Hybrid-LS, Hybrid-Random, and Multistart-5
- aggregate results used in the manuscript and supplementary information
- QNN and classical-readout controls
- both-strict and common-mask analyses
- local feature-geometry and local fixed-point-attractivity diagnostics
- lightweight GitHub Actions reproducibility checks

## Scope

The pre-specified primary comparison is Selected MRBI-QNN versus Zero-QNN. The tracked result is a positive mean balanced-accuracy difference whose 95% task-bootstrap interval includes zero. Post-confirmation selector, common-mask, geometry, and attractivity analyses are descriptive or mechanistic controls and do not replace the locked primary comparison.

No quantum-advantage or quantum-hardware claim is made.

Large feature caches, per-sample masks, and QNN prediction files are intentionally not included because they are regenerated by the provided scripts.
